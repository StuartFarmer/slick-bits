# Selective annotation with vote-k

Port of [HKUNLP/icl-selective-annotation/two_steps.py](https://github.com/HKUNLP/icl-selective-annotation/blob/main/two_steps.py), especially fast_votek, iterative_selection and prompt_retrieval. Paper: [2209.01975](https://arxiv.org/abs/2209.01975).

`SelectiveAnnotation(task, provider, evaluate, embed, annotate, uncertainty).run(inputs, budget=..., ...)` builds a cosine k-neighbor voting graph. Greedy coverage selects representatives with supporter weights 10^(-times already covered), excluding supporters already selected. fast_votek spends the full annotation budget on this objective. Full votek first labels an initial representative set, retrieves its nearest demonstrations for each unselected input, obtains uncertainty, partitions the descending uncertainty ranking into source 90%-sized strata, and adds the highest vote score in each stratum. Only initial labels inform uncertainty; labels of final selections are requested afterward.

embed maps strings to finite vectors. annotate(input) is an explicit label-oracle callback. uncertainty(demonstrations, input) returns a finite higher-is-less-confident measurement; log-likelihood callers negate their scores. Retrieval excludes cosine-identical examples and places the nearest last. evaluate(selected_examples) returns a finite higher-is-better final score. Result exposes selected indices, labels, graph, coverage, uncertainty ranking and callback counts. Configure `slick.prompts.TEMPLATE_ROOT = Path(selective_annotation.__file__).parent / "prompts"` before answer(input, demonstrations, provider=provider).

The port fixes source JSON string/integer key mismatches so second-stage selections update coverage, and explicitly excludes self from neighbors rather than dropping the sorted last item under ties. It handles tiny strata with width at least one and fills exhausted strata using vote coverage, where source fallback is random. Source token-budget retrieval is adapted to a fixed neighbor cap; tokenizer and context limits remain caller constraints. Diversity, facility-location, least-confidence baselines, model loading and task-specific annotation pipelines are excluded. Exceptions propagate. These tests do not reproduce annotation-efficiency results.
