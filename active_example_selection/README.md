# Active example selection

Port of [ChicagoHAI/active-example-selection/src/rl/agents/dqn_agent.py](https://github.com/ChicagoHAI/active-example-selection/blob/master/src/rl/agents/dqn_agent.py), [environment.py](https://github.com/ChicagoHAI/active-example-selection/blob/master/src/rl/environment.py) and [network.py](https://github.com/ChicagoHAI/active-example-selection/blob/master/src/rl/agents/network.py). Paper: [2211.04486](https://arxiv.org/abs/2211.04486).

`ActiveExampleSelection(task, provider, evaluate, represent, q_model).run(pool, parameters, ...)` learns sequential demonstration selection with an explicit STOP action. Rewards are task-score differences minus per-example cost, with an optional terminal peak-improvement bonus. The local algorithm owns exponential epsilon exploration, histories, no-repeat action spaces, replay snapshots, undiscounted target-network backups, L1 TD loss, optional conservative logsumexp penalty, gradient clipping, AdamW and periodic target copies. The released minimum of two nonterminal transitions in a sampled replay batch is retained. After training, a greedy rollout supplies the deployed demonstrations.

The evaluator receives ordered demonstrations and returns a finite higher-is-better score. represent(selected, available) returns model-derived state and action feature arrays. q_model(parameters, state_history, action_features) returns finite Q values for every available example **plus a final STOP action**, and their parameter Jacobians. The neural forward model may implement the source MLP/LSTM/linear architecture, including its learned stop vector, but cannot perform selection or updates. Model observations are copied before entering replay. The result records deployed indices/rewards, episodes, parameters, successful update count and each callback count. answer(input, provider=provider) renders deployed demonstrations.

Configure `slick.prompts.TEMPLATE_ROOT = Path(active_example_selection.__file__).parent / "prompts"` once. This port uses one fixed task/pool, fixed episode cap, no-repeat selection and constant learning rate (supported source options). Task-transfer sampling, offline replay loading, cyclic scheduling, model architecture construction and validation checkpoint choice are excluded. The baseline is measured once per run. No evaluation is charged for STOP. Errors propagate without retries. Tests verify loss derivatives, real replay learning, telescoping rewards and early stop; no training-performance reproduction is claimed.
