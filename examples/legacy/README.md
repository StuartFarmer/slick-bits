# Earlier problem-specific implementations

[2026-09-14-problem-specific.tar.gz](2026-09-14-problem-specific.tar.gz) preserves
the implementations before extraction of the generic agent flows: source, local
prompts, tests, dependency lists, benchmark configuration, and Dockerfiles.

These are historical examples, not dependencies of the current agents. The archive
retains the original execution restrictions; the current agents never execute
generated candidates. Existing run outputs and local environments remain in place.
