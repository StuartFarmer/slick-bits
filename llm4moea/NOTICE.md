# Upstream attribution

This Python implementation uses the algorithm and operator definitions in
[FeiLiu36/LLM4MOEA](https://github.com/FeiLiu36/LLM4MOEA), inspected at commit
`7fb29810abd891643914a0a7452c27956d38bddb`. No vendored pymoo tree, benchmark suite,
or MATLAB runtime is included. See README.md for deliberate differences.

Reference: Fei Liu, Xi Lin, Zhenkun Wang, Shunyu Yao, Xialiang Tong, Mingxuan Yuan,
and Qingfu Zhang. “Large Language Model for Multi-objective Evolutionary
Optimization.” arXiv:2310.12541.
