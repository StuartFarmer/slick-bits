# Ordered prompts

Port of [yaolu/ordered-prompt/entropy.py](https://github.com/yaolu/ordered-prompt/blob/main/entropy.py), [augment.py](https://github.com/yaolu/ordered-prompt/blob/main/augment.py) and [compeletion.py](https://github.com/yaolu/ordered-prompt/blob/main/compeletion.py). Paper: [Fantastically Ordered Prompts and Where to Find Them, 2104.08786](https://arxiv.org/abs/2104.08786).

`OrderedPrompts(task, provider, evaluate, classify).run(examples, classes=..., ...)` enumerates demonstration permutations, asks the model for synthetic inputs under each order, deduplicates their union, then obtains class scores for every order on that shared artificial development set. Global entropy is calculated from the histogram of argmax class predictions, with source 1e-5 mass for absent classes. Higher entropy ranks first; actual evaluator scores cannot affect ranking. One final evaluation of the best order returns a finite higher-is-better score. Result includes the top orders, all entropy values, artificial data and exact call counts. answer(input, provider=provider) uses the selected order.

Configure `slick.prompts.TEMPLATE_ROOT = Path(ordered_prompts.__file__).parent / "prompts"` once. classify(demonstrations, synthetic_inputs) is a batched model-scoring primitive, not a selection callback. Its finite matrix has one class column per label. Generation uses explicit JSON inputs instead of source task-specific regex extraction from completions; this intentionally changes the prompt boundary while preserving synthetic-data selection. Source fixed 24 iterations generalizes to a capped factorial enumeration. This ports the released global-entropy selector, not the paper's local-entropy variant, prompt-order performance averaging or benchmark correlation analysis. Errors propagate without retries. No gold development set is used to choose permutations.
