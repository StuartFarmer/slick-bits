# ReEvo implementation plan

## Current problem-agnostic implementation, 2026-09-14

The maintained implementation is now `reevo/agent.py`, with local Jinja prompts
and `tests/test_reevo.py`; the earlier application described below is archived.
This work uses the supplied paper and official `ai4co/reevo` commit
`6dce18257da5e11db2d138e417a2fffc5c72d05f` as references.

Boundary inspection: local Slick 0.3.0 returns unmodified strings for these
text prompts. The agent records raw candidates before nonblank/finite-score
checks, counts seed and rejected candidate attempts, catches evaluator
`ValueError`, and propagates other failures. Optional caller-owned sessions
carry history; default calls are independent. Keep these contracts.

## Historical application plan

Goal: implement the supplied ReEvo paper with the local Slick checkout.
Architecture: Slick prompt functions generate code and two levels of reflection;
an ordinary async Python loop owns selection, evaluation budgets and elitism.
An evaluator callback makes the search independent of the downstream solver.

Scope: the full Section 4 search method, Appendix B prompts, Table 8 defaults,
reflection/operator ablations, and a runnable TSP ACO example with black-box
prompting. The six-problem experimental suite and neural checkpoints are outside
this implementation. This directory is not a Git checkout; work stays in `reevo/`.

- [x] Add an offline integration check in `reevo/test_reevo.py` and observe it fail.
  Exercise scripted Slick providers against actual selection/evaluation logic;
  assert exact budgets, elite retention, reflection propagation, failures, ties,
  maximization, and held-out TSP evaluation. Run `python -m reevo.test_reevo`.
- [x] Implement `reevo/core.py` and `reevo/prompts.py`: task/config/individual
  records, async evaluator callback, initialization, uniform unequal-fitness
  parent pairs, short reflection, crossover, long reflection, elitist mutation.
  Count invalid candidates against the budget; propagate provider failures;
  return a stop reason for populations without any distinct valid pair.
- [x] Implement `reevo/tsp.py` and `reevo/__main__.py`: deterministic NumPy ACO,
  subprocess evaluation with timeout, fixed validation instances, held-out test
  instances, demo/API providers, and saved candidates/reflections/objectives.
  Report subprocess execution accurately: it is not a security sandbox.
- [x] Verify the checks and offline CLI in both prompt modes, document usage,
  paper correspondence and limitations in `reevo/README.md`, and add the root link.

Use stdlib plus Slick and NumPy. Keep prompt code executable with a fixed task
signature; do not impose a genetic-programming grammar on generated functions.
Retain raw LLM replies and evaluation errors. No live API benchmark is claimed
from the scripted demonstration.

Validation: `python -m reevo.test_reevo` passed, Ruff E/F/I checks passed,
and white-box/black-box demos each completed exactly 12 evaluations with
initialization, crossover, mutation, and two reflection rounds. Outputs are in
`reevo/runs/smoke-white/` and `reevo/runs/smoke-black/`. An independent review
found a CodexCLI/Git-directory prerequisite; the unnecessary CLI option was
removed, retaining demo and Slick LiteLLM providers. No live API calls were made.
