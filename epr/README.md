# Efficient prompt retrieval (EPR)

Port of [OhadRubin/EPR/find_bm25.py](https://github.com/OhadRubin/EPR/blob/master/find_bm25.py), [scorer.py](https://github.com/OhadRubin/EPR/blob/master/scorer.py), [DPR/dpr/data/biencoder_data.py](https://github.com/OhadRubin/EPR/blob/master/DPR/dpr/data/biencoder_data.py), [DPR/dpr/models/biencoder.py](https://github.com/OhadRubin/EPR/blob/master/DPR/dpr/models/biencoder.py) and [find_knn.py](https://github.com/OhadRubin/EPR/blob/master/find_knn.py). Paper: [2112.08633](https://arxiv.org/abs/2112.08633).

`EPR(task, provider, evaluate, encode).run(pool, parameters, ...)` mines BM25Okapi neighbors, scores every candidate demonstration by answer NLL, uses lowest-loss candidates as positive examples and highest-loss candidates as hard negatives, and trains a dual encoder using all-in-batch dot-product cross entropy. Query and context derivatives, chain-rule contraction with model Jacobians, clipping and AdamW updates are local. Random negative samples are optional and preserve source with-replacement semantics. retrieve(input, count=5) ranks indexed context embeddings by dot product and reverses the selected prompt order so the nearest example is last. answer(input, demonstrations, provider=provider) executes the resulting prompt.

The evaluator receives a query Example and one demonstration Example, returning finite **answer NLL to minimize**. encode(parameters, texts, role) executes query or context encoders and returns finite embeddings plus parameter Jacobians shaped (texts, embedding_dimension, parameter_count). A joint flat parameter vector can contain disjoint encoder parameters; unused derivative blocks are zero. Query texts exclude labels; context texts are input-tab-output. Returned state includes the learned parameters, supervision, losses, index and teacher/encoder call counts. Failures propagate without retries.

Configure `slick.prompts.TEMPLATE_ROOT = Path(epr.__file__).parent / "prompts"` once. NumPy exhaustive retrieval replaces FAISS; local BM25 replaces rank_bm25 with its default common-token IDF floor. Caller tokenizer defaults to whitespace splitting. Training explicitly excludes the same example by index rather than blindly dropping the highest BM25 hit. This implements QA context encoding, minibatch contrastive training and fixed-count inference; source BERT loading, training schedule/warmup, distributed negatives, validation checkpoint selection and token-budget packing are omitted. Full model Jacobians are practical for small models/adapters; large encoders may require caller Jacobian computation resources. Numerical tests cover both embedding gradients and actual parameter updates, not paper performance.
