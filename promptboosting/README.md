# PromptBoosting

Port of [UCSB-NLP-Chang/PromptBoosting/src/multicls_trainer.py](https://github.com/UCSB-NLP-Chang/PromptBoosting/blob/main/src/multicls_trainer.py), [label_set_util.py](https://github.com/UCSB-NLP-Chang/PromptBoosting/blob/main/src/label_set_util.py), [ensemble_training.py](https://github.com/UCSB-NLP-Chang/PromptBoosting/blob/main/ensemble_training.py) and [template.py](https://github.com/UCSB-NLP-Chang/PromptBoosting/blob/main/src/template.py). Paper: [Hou et al., ICML 2023](https://proceedings.mlr.press/v202/hou23b.html).

`PromptBoosting(task, provider, evaluate, token_scores).run(templates, training, labels, validation, classes=..., ...)` trains a discrete prompt ensemble without model parameter updates. token_scores(provider, contexts) returns a finite full-vocabulary matrix from a frozen model. Templates contain literal {input} placeholders and the model's mask/continuation marker. The local loop constructs weighted one-versus-rest token associations, assigns each token to a class, forms top-token Cartesian verbalizers (including reversed binary pairs), samples a candidate budget without replacement, and chooses the lowest weighted classification error. Better-than-chance weak learners receive SAMME weights; misclassified training examples are upweighted. Validation chooses the best ensemble prefix, with later equal scores winning. predict(inputs) performs the weighted class vote locally.

Template draws are random with replacement by default; random_templates=False uses the source's sequential-template option. Token scores are cached once per visited template and split. The evaluator receives only validation predictions and returns a finite higher-is-better score. Counts expose model batches, searched verbalizers and validations. Perfect learners stop with finite epsilon-clamped weight instead of the released zero-division failure; chance-only search raises ValueError. Other errors propagate.

Configure `slick.prompts.TEMPLATE_ROOT = Path(promptboosting.__file__).parent / "prompts"` once. The local Slick template renders contexts; full-vocabulary scoring is a model capability, not ordinary text generation. Source T5 template generation, tokenizer/model loading, dataset formatting, auxiliary fine-tuning and checkpointing are outside this port. Seeded NumPy Generator draws are not bit-identical to upstream global RNG draws. Tests establish update math and selection, not benchmark performance.
